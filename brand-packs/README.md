# Brand packs

One folder per brand, e.g. `brand-packs/swm/`. Confidential: this repo must stay private.

Each pack should contain:

- `profile.md` — company basics, what it sells, markets, short story
- `products.md` — products with real specs (prices only if public)
- `audience.md` — target buyers, markets, languages
- `voice.md` — personality, words to use and avoid, 3 sample captions you like
- `claims.md` — two lists: **verified claims** (with source) and **do-not-say claims**
- `logo/` — SVG or PNG
- `colours-fonts.md` — hex colours, font names (or font files in `fonts/`)
- `photos/` — 10 to 20 good product or company photos
- `docs/` — any brochures, company profiles, decks (PDF, DOCX, PPTX)

Anything missing is fine: NOVRA will show which Brand Brain sections still need input.
